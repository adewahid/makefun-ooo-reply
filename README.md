## The entry

`main.ts` writes a single one-line out-of-office auto-reply to `/output/entry.txt`:

> I'm away until Monday. Your email has been forwarded to the person best placed to help you: me, next week.

The joke turns the usual "contact someone else while I'm away" line on its head: the email is forwarded to the one person best placed to help — the sender's own future self, next week. It reads exactly like a real away message and lands on the first read.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
